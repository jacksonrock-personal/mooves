Phase 22 — Reminder day

The decision I made that you should look hardest at: selected slots are purple, not green

Green in this app has meant one thing since Screen 4, free now, and visible to your friends. A set slot is neither, it is private and it is in the future. Colouring it green would create a quieter second kind of green and undo the work Phase 20 did collapsing exactly that sort of ambiguity. Green appears in this whole phase only once, on the last screen, after you have confirmed. If you want the grid greener, that is the thing being traded away.

Why there is no screen for "no time zone yet"

The spec lists it as a state, and it is a real one, an existing user who has not opened the app since this shipped has no stored zone and gets no pushes. But it is invisible by design, the ritual works, the grid saves, and the zone is captured silently on that same app open. The only honest mockup of it is the screens above, unchanged. Inventing a banner for it would be inventing UI the spec deliberately does not have.

What the mockup cannot show, and where the risk actually lives

Roughly half this phase has no pixels, pg_cron ticking every fifteen minutes, pg_net calling an authed route, the 9am local window with its one hour of grace, the two idempotency stamps that stop a pocket buzzing twice. Phase 15's push pipeline had the same shape and the PRD called it invisible plumbing. Worth deciding whether that half gets reviewed some other way before the build starts, because it is where this phase can actually go wrong.

Deliberately absent

No streak, no count of weeks set, no "you have not set a week in a while", no completion meter on the grid, no badge on the Settings tab, no dot on the Feed tab, no second reminder for a slot you ignored, and nothing anywhere that tells a friend what you might be doing on Thursday.
