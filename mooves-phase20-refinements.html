The definition that changes. The spec currently says "a Moove has a day, a green does not". A "this weekend" Moove has no day, so that line dies. The replacement is stronger: a green is you being free, a Moove is a thing you're doing — availability versus content. Under that rule a coarse Moove is obviously coherent.

What this costs in data. `plans.start_at` stops being a real start time and becomes a sort key for coarse Mooves, so precision needs its own column. Coarse Mooves sort to the END of their window, so an exact Saturday 9am plan sits above "sometime this weekend".
